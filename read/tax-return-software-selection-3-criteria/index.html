確定申告ソフトは3条件で選ぶ｜比較前に確認

会社員で副業収入がある場合と、個人事業主では、用意する書類も入力作業も変わります。比較サイトを開く前に、自分の型を紙やメモアプリに書き出しておくと、比較表のどこを見ればいいかが絞れます。この記事では、申し込み前に確かめたい3条件を、今日そのまま使える手順で紹介します。

確定申告ソフトを選ぶ前に、まず自分の申告パターンを確認する

紙かメモアプリに、次の6点を書きます。

1. 税務上の立場と所得の種類：会社員の副業か、開業届を出した個人事業主か、不動産所得があるか。所得は給与のほかに、副業の雑所得や事業所得、不動産所得があるかを書きます。

2. 必要な書類：本業の源泉徴収票、支払調書、経費の領収書・請求書、控除の証明書。不動産があれば賃貸借契約書、修繕費の領収、減価償却の資料も加えます。

3. 今年の取引の規模：売上の相手の数、経費の数、現金取引の有無。

4. 帳簿：青色申告か白色申告か。記帳をこれから始めるか、すでに継続中か。

5. 作業に使える時間：平日夜か、週末か、まとまった休みか。去年の申告にかかった時間も書いておくと、今年の目安にできます。

6. 昨年の申告：e-Taxか書面か、自分でやったか税理士などに依頼したか。

立場によって必要な書類が違います。会社員で給与所得がある人は本業の源泉徴収票が必要です。副業の売上がある人は、事業所得（または雑所得）の計算に加えて、消費税や個人事業税が対象になるかどうかの確認も増えます。個人事業主の青色申告なら日々の仕訳が増えます。不動産所得がある人は、家賃の入金記録と修繕費、管理費の整理が加わります。必要書類や取引が増えるほど、ソフトに入力する項目や添付資料の管理も増えます。作業量の前提を決めておかないと、入力が終わらない状態になりやすいので、先にメモを手元に置いて、以下の条件1から順に当てはめてください。

条件1：どこまで自動化したいか（入力・仕訳・申告の作業範囲）

「自動化」は範囲が曖昧なので、次の3段階に分けます。

1. 記帳だけ：取引を仕訳に変換して帳簿を作る。集計や電子帳簿保存は自分で対応する。

2. 記帳＋請求書発行・入金消込：請求書を送り、入金の突合までソフト側で回す。

3. 記帳＋申告書類作成：確定申告書のフォームをソフトが組み立て、e-Taxでの送信まで見通す。

自分の業務に必要な段階を1つ決めます。副業で請求書を出さない人は2が不要なことが多く、売上が複数の口座に散らばる人は入金消込があると手戻りが減るとされています。逆に、請求書を頻繁に出すのに1しか選ばないと、二重入力が増えがちです。

手順は次の通りです。公式サイトの機能一覧で「レシート読取」「自動仕訳」「請求書」「消込」「e-Tax連携」の各項目を探します。先ほどのメモの書類や作業が、どの機能で処理できるかを線で結び、残る別作業を確認します。無料体験がある場合は、領収書2枚と明細1か月分で試し、手直しの量を見てください。

注意点：「自動」と表示されていても、口座明細の摘要欄が自由な文言だと、仕訳が自動で決まらない場合があります。初年度は、自動仕訳の結果を全件見るつもりで確認します。確認を省くと、後から直す手間が増えるケースが少なくありません。

条件2：銀行・カード・給与・請求書などの連携先が揃うか

利用中のものを書き出したうえで、公式サイトの対応表と照合します。対応表はソフトごとに更新頻度が異なるため、見た日付もメモに残してください。

・銀行口座と支店名

・クレジットカードや電子マネーの名称

・給与明細の受け取り方（紙、PDF、給与システムの画面）

・請求書の発行元・受取先

・会計ソフトやECツールとの連携の要否

自分のよく使う銀行やカードが入っていない場合、自動取込の恩恵を受けにくくなります。その場合はCSV取り込みなど手動の経路があるか、手間を確認しましょう。対応表に掲載があっても、実際の連携設定がスムーズかどうかは、無料体験中に1口座だけつないで確かめるのが確かめやすい方法です。

条件3：費用・サポート・税務調査への対応を確認する

最後に、申し込み前の確認として、費用とサポートの枠組みを見ます。初期費用、月額・年額、申告時期のみのプラン有無、追加料金が発生しうる機能（給与計算、消費税申告、その他申告書の添付など）を、公式の料金ページで把握します。キャンペーン価格は適用条件や期間が限定されていることがあるため、請求額が確定するまで表示を保存しておくと安心です。

あわせて、問い合わせ窓口（チャット、メール、電話）の対応時間、初めて使う場合の導入支援、データの保存期間やバックアップ方法も確認します。税務調査が想定されるケースでは、帳簿データの出力形式や保存期間が要件に合うかを、事前に税務署や税理士に確認するのが安心です。金額やサポート内容は変更される可能性があるため、契約前に公式ページで最新情報を確認しておくことをおすすめします。

よくある質問

会社員の副業でも確定申告ソフトは必要ですか？

副業所得が一定額を超えるなど申告が必要な場合は、記帳と申告書作成をまとめて行えるソフトが便利です。必要かどうかの判定は国税庁の案内で確認してください。

無料の会計ソフトと有料版はどう選べばよいですか？

まず無料範囲で入力と連携を試し、請求書発行やサポート、複数事業の管理など不足する機能が出た時点で有料版を検討すると判断しやすくなります。

料金はどこで確認すればよいですか？

各サービスの公式料金ページで、最新のプラン内容・無料期間・更新時の金額を確認してください。当記事では具体的な金額は記載していません。
