出発前に済ませておくこと

まず、普段使わないネットワークの登録を整理します。自動接続が有効なままだと、過去に使ったSSIDへ意図せずつながることがあるためです。

iPhoneはWi-Fi設定の各ネットワーク詳細から削除、Androidはインターネット設定の「保存済みネットワーク」から削除、Windowsは「既知のネットワークの管理」、MacはWi-Fiの詳細にある既知のネットワークで整理します。ふだん行かない店の登録は残さない方針にします。

あわせて、OS、ブラウザー、メールや会議アプリ、セキュリティソフトに保留中の更新がないか確認します。OS更新は「設定→システム→更新（またはソフトウェア・アップデート）」で確認し、適用後は再起動します。セキュリティソフトは定義ファイルの最終更新日時を画面で見て、数日前のままなら更新を実行します。大きな更新は自宅や職場の回線で済ませ、現地では作業に集中できる状態にしておきます。

接続前にSSIDと案内を照合する

現地では、つなぐ前にSSIDが施設の正式な案内と一致するか確認します。店内掲示、レジ横のカードやPOP、公式サイト、施設配布の案内、社内ポータルのいずれかと、名前のつづりを見比べます。大文字・小文字、数字、ハイフンの違いに注意し、似た名前が複数ある場合は一文字ずつ照合します。末尾に「_WiFi」「_Free」が付いた名前も、偽SSIDの例として注意します。一致しないものには接続しません。

以前使った公衆Wi-Fiに自動でつながりそうなときも、そのままにしません。同じ名前が別の場所で使われていることがあるため、今回の案内と合っているか見てから接続します。

案内に認証ページのURLやサポート連絡先が載っているかも確認します。記載がなければ、店員や窓口に「Wi-Fi名、パスワードの有無、ログイン画面が出るか」をセットで聞きます。

認証ページと入力情報を確認する

接続直後にブラウザで任意のサイトを開き、公式案内に記載の認証ページへリダイレクトされるか確認します。リダイレクト先のURLが案内と一致するかも見ます。接続後に「保護されていない」などの警告表示が出ていないか確認します。

認証ページでメールアドレス、SNSログイン、アンケートなどを求められたら、必要な情報だけを入力します。業務用と私用のどちらで登録するかは先に決めておきます。有料プランを使う場合は、料金、支払い方法、領収書の有無を先に確認します。

偽SSIDに接続して認証情報を入力し、アカウントを乗っ取られた例もあります。似た名前のSSIDは、店員に確認してから接続します。

公衆Wi-Fi利用中に切っておく設定

ファイル共有は、Windowsなら「ネットワークと共有センター」→「共有の詳細設定」でファイルとプリンターの共有をオフ、macOSなら「システム設定」→「一般」→「共有」でファイル共有をオフにします。公衆Wi-Fi利用中はオフのままにします。

Bluetoothは使わない場合はオフにします。使う場合は「検出可能」をオフにし、ペアリング済みの機器だけを接続します。近距離共有（AirDropなど）も、必要がないときはオフにしておきます。

作業前の最終チェック

接続できたら、次を順に確認します。SSIDは施設の案内と一致しているか。認証ページのURLは案内どおりか。「保護されていない」警告は出ていないか。ファイル共有、Bluetooth、近距離共有はオフか。入力した情報は必要最小限か。有料の場合、料金と領収書の扱いを確認したか。項目が多いと感じたら、SSIDと認証ページの2点だけでも先に見ておくと、判断を誤りにくくなります。

会社の端末を使う場合は社内の情報セキュリティルールが優先です。機密性の高い資料を扱う予定があるときは、公衆Wi-Fiでの作業を避け、会社指定のVPNやモバイル回線、テザリングを検討します。作業中も、共有設定が戻っていないか、見慣れないポップアップが出ていないかをときどき確認します。

確認は一度で終わらせず、接続先を変えるたびにSSIDの照合からやり直すと安心です。
